HOW IT WORKS

Static QR codes — one less redirect

Many online QR codes are actually "dynamic" — the image points to the generator's server, which redirects to your real target. If they shut down, change rules or start charging, every code you printed dies at once. This tool makes static codes: your content is encoded into the pattern itself, scanned with no server in between, permanent — and generated locally, never uploaded.

Pick type & fill

URL, Wi-Fi, vCard, phone, SMS, email; URLs auto-prefix https:// so scans open.

Style it

Apply a template, or customize gradient, dots and corners, add a brand / custom logo.

Download

Export a high-res PNG or a vector SVG that scales losslessly — crisp in print and on the web.

FAQ

FAQ

How do I create a QR code for free?
Pick a content type, fill it in, and the code generates live. Apply a template or customize colors, gradient, dot style and a logo, then download PNG or SVG. Free, no watermark, unlimited.
Can it make Wi-Fi and vCard QR codes?
Yes. Wi-Fi encodes network + password so a scan connects (camera support); vCard follows the standard so a scan can save the contact. Phone, SMS and email too.
My code won't scan / open — what now?
For a URL, ensure it has https:// (auto-prefixed here). Very light/low-contrast colors or an oversized logo hurt scannability — use a dark foreground, light background, and test-scan with your phone.
Will it expire? Commercial-safe?
Never expires — static codes encode content into the image itself, no server. Built-in icons come from Simple Icons (mostly CC0), but trademarks belong to their owners (identification use only).
