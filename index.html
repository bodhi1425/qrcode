HOW IT WORKS

静态二维码,扫一次少一次中转

很多在线二维码其实是“活码”——图片指向生成网站的服务器,扫描时再跳转到你的真实地址。一旦对方停服、改规则或收费,你印出去的码就集体失效。这个工具生成的是静态码:你的内容被直接编码进图案本身,扫描不经任何服务器、永久有效,而且全程在浏览器本地完成、不上传。

选类型填内容

网址、Wi-Fi、名片、电话、短信、邮件;网址会自动补全 https:// 让扫码可跳转。

挑样式

套用风格模板,或自定义渐变色、码点、定位角,加品牌 / 自定义 logo。

下载使用

导出高清 PNG 或可无损放大的矢量 SVG,印刷、网页都清晰。

FAQ

常见问题

怎么免费生成二维码?
选内容类型(网址 / Wi-Fi / 名片 / 电话 / 短信 / 邮件),填入内容,二维码实时生成。可套用风格模板或自定义颜色、渐变、码点样式、加中心 logo,然后下载 PNG 或 SVG。免费、无水印、不限次数。
能生成 Wi-Fi 和名片二维码吗?
能。Wi-Fi 模式填网络名和密码,扫码即可自动连接(手机相机或微信扫一扫支持);名片模式按 vCard 标准生成,扫码可一键存入通讯录。还支持电话、短信、邮件等类型。
扫码后网址不能跳转 / 扫不出怎么办?
网址类型会自动补全 https://,确保扫码识别为链接可跳转。若用了浅色 / 低对比配色或过大的 logo,可能影响识别——建议前景深、背景浅、对比明显,生成后用手机实扫确认。
生成的二维码会过期吗?能商用吗?
不会过期。生成的是静态码,内容直接编码进图片本身、不经服务器,永久有效。内置图标来自 Simple Icons(图标本身多为 CC0),但品牌商标权归各品牌方,仅供识别用途。
